## エグゼクティブ・サマリー

**問い。** 市場の競争度（企業数 N）が上がると、ニューケインジアン・フィリップス曲線（NKPC）の傾きはフラット化するのか。HSA（Herfindahl-Style Aggregator）NKPC を状態空間モデルとして構造推定し、傾き `kappa_t = kappa_0 + delta·Nbar_t` の競争度依存係数 `delta` の符号を識別する。

**結論（3行）。**

1. **失業ギャップ仕様で `delta > 0` が頑健**（core CPI で +0.023、P(delta>0)≈1.0）。含意される傾き `kappa_t` は標本期間で **0.12 → ≈0 にフラット化**する。競争度上昇が NKPC を平坦化させる、という HSA の予測と整合。
2. **インフレ指標を core CPI に統一すると、出力ギャップ系（BN・HP）でも delta の符号が正に反転**する。headline CPI では BN で負・HP でゼロだった係数が、core では BN +0.011・**HP +0.029（P≈1.0）** となり、失業ギャップと符号が揃う。
3. この符号の食い違いは **2008Q3–2009Q4 の石油ショック起因の headline CPI 変動**が原因であることを FWL/Okun 分解で特定済み。core への切替はサンプラーを変えずにこの汚染を除去する最もクリーンな方法。

**中核テーブル（本レポートの"顔"）。** ベースライン、1982Q1–2012Q4（T=124）、quarterly、無制約、hsa_steady。

| 活動指標 | headline CPI: delta | **core CPI: delta** | core の kappa_t（始点→終点） |
|---|---|---|---|
| 失業ギャップ | +0.030 (P=1.00) | **+0.023 (P=1.00)** | 0.120 → -0.005 |
| 出力ギャップ HP | -0.002 (P=0.43) | **+0.029 (P=1.00)** | 0.161 → -0.004 |
| 出力ギャップ BN | -0.013 (P=0.18) | **+0.011 (P=0.88)** | 0.062 → 0.005 |

**スコープ条件。** この結果は 1980 年代（Volcker 期）を含む標本に固有である。post-1988 標本では失業フィリップス曲線が既に平均的にフラットで傾きの変動余地が乏しく、delta ≈ 0 となる。この限界は隠さず報告する。

## 1. イントロダクション

インフレ動学の中心的な未解決問題の一つは、フィリップス曲線の傾き（限界費用・スラックへのインフレ感応度）が時間を通じて低下してきたように見えること――いわゆる「フィリップス曲線のフラット化」――の構造的原因である。本稿は、この傾きの時変を **市場の競争度** に結びつける仮説を、ベイズ状態空間 MCMC によって定量的に検証する。

理論的基礎は Matsuyama–Fujiwara / Fujiwara–Matsuyama の HSA（Herfindahl-Style Aggregator）NKPC である。HSA では企業間の戦略的相互作用が集計需要曲線の曲率を通じて価格設定の弾力性を左右し、その結果、フィリップス曲線の傾き `kappa_t` が競争構造（本稿では企業数 N の低頻度トレンド `Nbar_t`）に依存する。具体的には

```
kappa_t = kappa_0 + delta · Nbar_t
```

という線形の傾き方程式が含意され、`delta` の符号が「競争度が傾きをどちら向きに動かすか」を決める。

**本稿の貢献は3点。** 第一に、HSA-NKPC を完全な状態空間モデル（インフレ観測式＋競争度の三成分分解）として定式化し、Gibbs/FFBS で構造推定する。第二に、傾きの競争度依存 `delta` を、複数の活動指標（失業・出力ギャップ・労働分配率・逆マークアップ）とインフレ指標（headline/core CPI）を横断して識別し、その頑健性を体系的に評価する。第三に、係数符号が活動指標間で食い違う原因を FWL/Okun 分解で解剖し、core CPI への統一がそれを解消することを示す一方で、結果が競争度指標と標本期間に依存するスコープ条件を明示する。

**結論の先出し。** delta>0（競争度上昇が傾きをフラット化）は失業ギャップで頑健であり、core CPI に統一すると出力ギャップ系でも符号が揃う。ただし post-1988 標本ではこの信号は消える（識別を担う 1980 年代が外れるため）。

## 2. 理論的枠組み

### 2.1 観測方程式

すべてのモデル変種は共通の NKPC 観測式を持つ：

```
pi_t = alpha·pi_{t-1} + (1 - alpha)·E_t pi_{t+1} + kappa_t·x_t - theta_t·Nhat_t + e_t
```

- `pi_t`：インフレ率（headline または core CPI）。
- `x_t`：実体活動ギャップ（失業ギャップ、BN/HP 出力ギャップ、労働分配率ギャップ、逆マークアップのいずれか）。
- `kappa_t`：時変フィリップス曲線傾き。
- `Nhat_t`：競争度のギャップ（循環）成分。`theta_t` はその係数。
- `E_t pi_{t+1}`：期待インフレ（`Epi` 列。headline CPI ベースの調査/近似）。

### 2.2 競争度の分解と傾き方程式

観測される競争度 `N_obs_t` を三成分に分解する：

```
N_obs_t = Nbar_t + Nhat_t + nu_t
```

- `Nbar_t`：ドリフト付きランダムウォーク・トレンド。傾き方程式の駆動要素。
- `Nhat_t`：定常 AR(2) ギャップ（定常領域に切断）。
- `nu_t ~ N(0, sigma_N^2)`：測定誤差。

傾きはトレンド競争度に線形依存する：`kappa_t = kappa_0 + delta·Nbar_t`。同様に、フルモデルでは `theta_t = theta_0 + gamma·Nbar_t`。

### 2.3 予測命題

HSA の含意は、競争度トレンド `Nbar_t` の上昇が傾き `kappa_t` を低下させる（`delta` が「フラット化」と整合する符号を持つ）こと、そして観測期間での `Nbar_t` の推移に沿って `kappa_t` が単調に平坦化していくことである。本稿の実証はこの2点を検証する。

## 3. データ

**標本。** 四半期、1982Q1–2012Q4（T=124）を主標本とする。頑健性のため pre/post-2008、start-1988、end-2019、exclude-COVID の各サブ標本も推定する。

**インフレ指標。** headline CPI（`pi_cpi`）と **core CPI**（`pi_cpi_core`）。補助的に core PCE。期待項 `Epi` は headline ベースで固定し、指標切替時も共通に用いる（期待の楔は定数・alphaに吸収される旨を後述）。

**実体活動ギャップ（5種）。**
- 失業ギャップ（`unemp_gap`）――主力。
- 出力ギャップ BN（`output_gap_bn`）――生データ供給の Beveridge–Nelson 型サイクル。
- 出力ギャップ HP（`output_gap_hp`）――`100·output` に HP フィルタ。BN と同じ 100-log-point 単位。
- 労働分配率ギャップ HP（`labor_share_gap_hp`）――`100·log(労働分配率指数)` に HP フィルタ。
- 逆マークアップ（`inv_markup`）。

**競争度指標。** 競争度系列は Gustavo の企業カウント型 N（`N_Gustavo`、年次を PCHIP で四半期補間）。HSA の N は文字どおり戦略的競争者の「数」であり、企業カウント指標が理論に対応する。

**単位規約。** 競争度の既定変換は `(100·log(N) - 標本平均) / 10`。したがって `Nbar`・`Nhat` の 1 単位は平均まわりの 10-log-point 変化であり、報告される `delta`・`theta`・`theta_0`・`gamma` はすべてこの 10-log-point スケール上の値である（二重スケーリングをしない）。

## 4. 計量モデルと推定

### 4.1 モデル変種

5 つのモデルは傾き制約のみで異なる：

| モデル | kappa_t | theta_t | 位置づけ |
|---|---|---|---|
| `ces` | 定数 | 0 | 従来型 NKPC ベースライン |
| `hsa_steady` | `kappa_0 + delta·Nbar_t` | 0 | **主力**。傾きがトレンド競争度で時変 |
| `hsa_dynamic` | 定数 | 定数 | Nhat チャネルのみ |
| `hsa_const_theta` | `kappa_0 + delta·Nbar_t` | 定数 | hsa_full で gamma=0 固定 |
| `hsa_full` | `kappa_0 + delta·Nbar_t` | `theta_0 + gamma·Nbar_t` | フルモデル |

`hsa_const_theta` を置く理由は、`gamma` の回帰子 `Nhat·Nbar` が `theta_0` の回帰子 `Nhat` とほぼ共線（約 98%）で `gamma` が識別されないためである。

### 4.2 推定

競争度の三成分は Kalman/FFBS で同時に抽出し、係数ブロックは共役ガウス（＋必要に応じ符号制約のための棄却サンプリング）で更新する。`hsa_full` は明示的な N 測定誤差 `sigma_N^2` を持ち、`Nhat|Nbar`／`Nbar|Nhat` の二ブロック FFBS は厳密な Gibbs ステップである。

**プライヤ。** kappa 系は物理単位で指定し、内部で `KAPPA_SCALE=100` 変換。N 状態ショック・測定分散のプライヤは二乗 10-log-point 単位（≈0.01 decade）に合わせる。既定は baseline（＋弱/強プライヤの頑健性）。

**収束。** 主力の hsa_steady は R-hat ≤ 1.01 前後で良好。hsa_full の一部セル（weak/tight/annual_q4）は R-hat 1.1–1.3 と収束が弱く、過度に読まない。以降、中心的推論は **hsa_steady を workhorse** とする。

![競争度の事後分解 N = Nbar + Nhat](/Users/satoshi/GitHub/NKPC_HSA_MCMC/results/figures/unemployment_gap_core/competition_decomposition_path.png)

*図 4-1. 競争度の事後分解（失業ギャップ core）。トレンド Nbar とギャップ Nhat はどの仕様でもよく識別される（RMSE ≤ 0.01）。ただし「状態がきれいに見える」ことは kappa/delta の識別を意味しない。*

## 5. 主要結果

### 5.1 中心結果：失業ギャップで delta>0、傾きはフラット化

主標本・baseline・hsa_steady で、失業ギャップ core CPI の傾き競争度依存は

```
delta = +0.0227 (sd 0.0075),  P(delta>0) = 1.00
kappa_0 = +0.051 (P=0.997)   ← 平均競争度での傾きは正（曲線は健在）
```

含意される傾き `kappa_t` は標本期間を通じて **0.120 → -0.005** へ低下する。すなわち競争度トレンド上昇に沿ってフィリップス曲線が平坦化していく、という HSA の予測がそのまま観察される。headline CPI 仕様でも delta=+0.030（P=1.00）と符号・強さは一致し、失業ギャップの結果はインフレ指標の選択に対して頑健である。

![傾き kappa_t の時変経路（失業ギャップ core）](/Users/satoshi/GitHub/NKPC_HSA_MCMC/results/figures/unemployment_gap_core/kappa_t_path.png)

*図 5-1. 推定された kappa_t 経路。競争度トレンドの上昇に伴い傾きが 0 近傍まで平坦化する。*

### 5.2 core CPI への統一：出力ギャップ系でも符号が揃う

出力ギャップ系（BN・HP）は headline CPI では傾き競争度依存が負ないしゼロに見えるが、**core CPI に切り替えると符号が正に反転**する。

| 出力ギャップ (hsa_steady) | headline delta | **core delta** | core の kappa_t（始点→終点） |
|---|---|---|---|
| BN | -0.0128 (P=0.18) | **+0.0106 (P=0.88)** | 0.062 → 0.005 |
| HP | -0.0024 (P=0.43) | **+0.0289 (P=1.00)** | 0.161 → -0.004 |
| 失業（参考） | +0.0302 (P=1.00) | +0.0227 (P=1.00) | 0.120 → -0.005 |

とりわけ **HP 出力ギャップ × core CPI は delta=+0.029（P=1.00）** と、失業ギャップと同等の強さで delta>0 を示す。core への統一後、失業・HP・BN の3系統すべてで kappa_t が期間内に低下（フラット化）する。逆に headline BN では kappa_t が 0.025 → 0.096 と *急峻化* しており、これが後述のオイル汚染による人工物であることを 7 章で示す。hsa_full でも同じパターン（BN core +0.011、HP core +0.028、いずれも符号一致）が得られ、結果はモデル変種に頑健である。

![core CPI 結果の周波数横断](/Users/satoshi/GitHub/NKPC_HSA_MCMC/results/figures/core_delta_gamma_freq.png)

*図 5-2. core CPI 仕様の係数（周波数横断）。四半期・annual_q4 いずれでも delta の符号は保たれる。*

### 5.3 傾き水準 kappa_0：曲線は生きているか

平均競争度での傾き `kappa_0` は、失業・出力ギャップ系でいずれも正である（HP headline で +0.142、失業 core で +0.051）。core にすると水準は下がる（headline がオイルで水増しされていた分）が、符号は正のまま保たれ、フィリップス曲線が標本平均において機能していることを示す。CES の定数傾き `kappa` も同傾向（HP core で +0.091、P=1.00）。inv_markup と labor_share ではインフレ信号がほぼ無く（OLS 傾き ≈ 0）、kappa_0・delta はプライヤ支配となる。

## 6. 傾きが定数のとき：ベンチマークと時変の必要性

時変傾きの結果（5章）を正しく評価するには、傾きを定数に固定したベンチマークが要る。本章は定数傾きモデル（`ces` と `hsa_dynamic`）を提示し、そのうえで「傾きを競争度で時変させることが当てはまりを改善するか」を正式に比較する。

### 6.1 定数傾きモデル（CES / hsa_dynamic）

**CES（定数 kappa）。** 標準的な NKPC 傾きは、活動指標によって明確に正の値を取る。ベースライン・1982Q1-2012Q4・quarterly の定数傾き `kappa` は次のとおり。

| 活動指標 | CES kappa（headline） | CES kappa（core CPI） |
|---|---|---|
| 失業ギャップ | +0.056 (P=0.96) | +0.039 (P=0.99) |
| 出力ギャップ HP | +0.138 (P=1.00) | +0.091 (P=1.00) |
| 出力ギャップ BN | +0.059 (P=0.92) | +0.032 (P=0.90) |
| 労働分配率ギャップ | -0.008 (P=0.46) | - |
| 逆マークアップ | +0.007 (P=0.52) | - |

出力ギャップ HP と失業（とくに core）では定数傾きがはっきり正で、フィリップス曲線が標本平均で機能していることを確認できる。一方、労働分配率ギャップと逆マークアップは定数傾きすら 0 と区別できず、インフレ信号がほぼ無い（これらの仕様では時変の kappa_0・delta もプライヤ支配となる）。

![定数傾き kappa の事後分布（CES）](/Users/satoshi/GitHub/NKPC_HSA_MCMC/results/figures/posterior_density_kappa.png)

*図 6-1. CES の定数傾き kappa の事後分布。HP 出力ギャップ・失業で明確に正側に位置する。*

**hsa_dynamic（定数 kappa ＋ 定数 theta）。** 競争度ギャップ `Nhat` のチャネルを加えても定数傾き `kappa` は CES とほぼ同一（例：失業 +0.052、HP +0.137、BN core +0.036）。追加された定数 `theta` は弱い負に出るが、四半期頻度では実質的に未識別である：`Nhat` の四半期変動は年次系列の PCHIP 補間による人工物であり、annual_q4 頻度に落とすと theta はプライヤに回帰する。したがって定数 theta のチャネルは本データでは情報をほとんど持たない。

|---|---|---|---|
| 失業ギャップ | -0.019 | 0.34 | 未識別（プライヤ寄り） |
| 出力ギャップ HP | -0.017 | 0.35 | 未識別 |
| 出力ギャップ BN | -0.069 | 0.11 | 四半期補間の人工物、annual_q4 で消失 |

### 6.2 時変 kappa は定数 kappa に勝るか（モデル比較）

定数傾き（CES）と、傾きを競争度で時変させる `hsa_steady` を、事後予測スコア（大きいほど良い）と傾き競争度依存の消失 `delta=0` に対する Savage-Dickey ベイズファクター（BF10、大きいほど時変を支持）で比較する。ベースライン・quarterly・無制約。

| 活動指標 | CES 予測スコア | hsa_steady 予測スコア | 改善 | BF10（delta=0 に対し） |
|---|---|---|---|---|
| 失業ギャップ | -119.9 | **-115.3** | **+4.6** | **10.2** |
| 出力ギャップ BN | -120.8 | -119.6 | +1.2 | 1.6 |
| 出力ギャップ HP | -114.1 | -114.0 | +0.1 | 0.8 |
| 労働分配率ギャップ | -121.9 | -121.4 | +0.5 | 1.2 |
| 逆マークアップ | -121.9 | -121.9 | 0.0 | 1.0 |

**判定。** 失業ギャップでは、傾きを競争度で時変させることが予測スコアを約 4.6 点改善し、`delta=0`（定数傾き）は約 10:1 で棄却される――時変傾きは明確にペイする。headline の出力ギャップ系では改善は限界的（BF10 0.8-1.6）だが、これは 5-7 章と整合する：出力ギャップの時変信号は core CPI 仕様に宿っており、その core 仕様はまだモデル比較パイプラインに組み込まれていない（10章の次アクション）。労働分配率・逆マークアップはインフレ信号自体が無いため、定数と時変は当てはまり上ほぼ同等になる。

**注意（logML について）。** 本章の判定は予測スコアと SDDR に基づく。Chib 周辺尤度（logML）は annual_q4 ブロックの欠測 N 非対応バグで汚染されており（10章 未解決事項）、定数 vs 時変の logML 直接比較には用いない。

## 7. 識別の解剖：なぜ headline は誤誘導するか

活動指標間の delta 符号の食い違いは、モデルの不具合ではなく **特定の 6 四半期に集中したデータ情報** に由来する。OLS-アナログの FWL（Frisch–Waugh–Lovell）分解と Okun 分解により、次を確認した（T=124、自仕様の事後 Nbar を使用）。

1. **エピソード寄与。** BN の delta = -0.046 のうち、**2008Q3–2009Q4 の 6 四半期だけで -0.046（100%）** を占める。この 6 四半期を落とすと BN は **+0.088（t≈+2.1）** に反転し、失業（+0.058）と符号が一致する。1983–86 の Volcker 期の寄与は -0.003 と副次的。
2. **Okun 分解。** BN ギャップは失業ギャップと分散を R^2=0.11 しか共有しない。BN delta の Okun 共通成分は +0.026（失業の事後 +0.029 と一致）で、**Okun 残差成分 -0.072 が食い違いの全て**を担う。
3. **メカニズム。** 2008–09 に GDP が労働市場より早く深く崩落（Okun 残差 -2.4）した時期に、石油が headline CPI を大きく振らせた（+2.3 → -2.2）。BN はこれを「巨大なスラック × 巨大なディスインフレ ＝ 急峻な傾き」と、しかも最低 Nbar 期に読むため delta<0 を出す。
4. **core CPI が指標を整合させる。** LHS を core に替えると、この石油由来の楔が除去され、BN・HP・失業のすべてで delta が正側に揃う（5.2）。期待項 `Epi` は headline ベースのままだが、その楔は定数・alpha に吸収され、傾き係数の識別は汚染されない。

補強として、**pre-2008 標本**（1982Q1–2007Q4）では BN headline delta が -0.013 → +0.002（P=0.55）と負符号が完全に消滅し、オイル・エピソード診断がベイズモデル内部でも確認される。

---

## 8. 頑健性

主結果（失業ギャップの delta>0）を以下の軸で確認した。

- **プライヤ。** weak/tight プライヤでも失業 delta は +0.02-0.04、P≈1.0 を維持。
- **競争度周波数。** annual_q4（N を Q4 のみ観測し Q1–Q3 を欠測として状態空間で補完）でも delta 方向は不変（失業 +0.022-0.029、P≈1.0）。なお四半期での theta/gamma の「有意性」は PCHIP 補間の人工物で、annual_q4 ではプライヤ支配に戻る（＝四半期頻度で theta/gamma は実質未識別）。
- **サブ標本。** pre/post-2008、start-1988、end-2019、exclude-COVID。失業 core は端点標本で弱まるが方向は保つ。BN core は weak/tight/restricted/pre-2008/end-2019/exclude-COVID で P 0.67–0.88 と正を保つ一方、annual_q4 と start-1988 で ~0 に弱まり、「方向は一致するが弱識別」と位置づける。
- **係数制約。** kappa_t≥0 のハード制約（別事後・別台）でも失業 delta の符号は保たれる。制約付きは「制限付き頑健性仕様」として別掲し、無制約ベースラインと混ぜない。

## 9. スコープ条件：結果が消える領域

誠実さのため、主結果が **成立しない** 設定を明示する。

- **post-1988 標本。** 開始年を 1988 にすると失業 delta は弱まる（信用区間が 0 に寄る）。post-1988 の失業フィリップス曲線は平均的に既にフラット（kappa_0≈0）で、傾きの変動余地が乏しいため。
- **識別エンジンは 1982–87 の Volcker 期。** 傾きが明確に生きており競争度トレンドが標本最低だったこの時期が、競争依存の識別を担う。ここを外すと証拠の大半が消える。

**論文での枠組み。** 主結果は 1980 年代（Volcker 期）を含む標本に固有である。隠さずスコープ条件として報告する。

## 10. 結論

競争度トレンドの上昇はフィリップス曲線の傾きをフラット化させる。失業ギャップ仕様では `delta>0`（傾きの競争度依存）が頑健に得られ、含意される `kappa_t` は 0.12 から 0 近傍へ平坦化する。インフレ指標を core CPI に統一すると、出力ギャップ系（とりわけ HP）でも同じ符号・同じフラット化が現れ、活動指標間の見かけの不一致が 2008–09 金融危機（油価主導の headline 変動）に帰着することを識別分解で示した。ただしこの結論は 1980 年代（Volcker 期）を含む標本に固有であり、post-1988 標本では傾きの変動余地そのものが乏しく信号は消える。

**含意。** 競争政策・市場構造の変化がインフレ動学の感応度に影響しうるという HSA の含意に、少なくとも 1980 年代以降の企業カウント指標のもとでは実証的支持が得られる。**限界。** 傾きの時変を駆動する識別情報が特定エピソード・特定指標に集中しており、競争度の測定（カウント型 vs テキスト型）と標本期間の選択に結論が依存する。
