# Exact-N HSA NKPC nested-validation specification

Status: **implementation specification, frozen before estimation**  
Revision: `hsa-nested-validation-v3-price-separated-joint-only`  
Primary language of reporting: English  
Output bundle: `tests/hsa_nested_validation/results/`

## 1. Objective and confirmatory claims

This experiment answers three questions in order.

1. Do the PPI and Core CPI NKPCs separately require a competition slope
   channel, a direct competition channel, or both?
2. In the theory-near inverse-markup cell, are both the slow-state slope channel
   and the cyclical direct channel empirically needed?
3. Conditional on a pre-declared external HSA multiplier, does the sharp HSA
   equality fit without a material loss of predictive performance?

The experiment does **not** claim that an unrestricted multiplier is identified
from the NKPC. A model with both `lambda` and `theta` free is retained only as an
identification diagnostic because the slope data identify their product.

The confirmatory analysis is static. Time-varying `theta`, quadratic `kappa`, and
the corresponding dynamic HSA restriction are deferred until the static ladder
passes the decision rules in Section 12.

## 2. Data and sample

### 2.1 Inflation cells

The two inflation outcomes are estimated separately. They never share NKPC
coefficients or a slow/cycle posterior.

- PPI: `pi_ppi`, with lag `pi_ppi_prev`.
- Core CPI: `pi_cpi_core`, with lag `pi_cpi_core_prev`.
- Expected inflation: `Epi_spf_gdp` in both cells, matching the existing
  identification test used as the implementation reference.
- Competition indicator: Capital IQ firm-weighted effective-firm count,
  `N_capitaliq_firmw`, used only to allocate within-year changes.
- Annual competition benchmark: `N_Gustavo_annual_q4`.
- Estimation sample: `1974Q4` through `2013Q4`, after a common complete-case
  filter. The same period index must be used by every nested model.

### 2.2 Activity cells

Each inflation outcome is paired separately with both activity variables:

- Negative unemployment gap: `unemp_gap = NROU - UNRATE`. Its competition
  coefficients are reduced-form and are not used for the quantitative HSA
  equality.
- Inverse-markup benchmark: `markup_BN_inv`.
- Unit-scale benchmark: `b_x = 1`, reported explicitly as an assumption.

This creates four independent cells: PPI/negative-gap, PPI/inverse-markup,
Core-CPI/negative-gap, and Core-CPI/inverse-markup. Model comparisons are made
only within a cell.

## 3. Competition coordinate and annual constraints

Let `F_y` be the annual Gustavo effective-firm count. Define the uncentered
empirical competition coordinate

```math
q_y^G = 10\log F_y.
```

One unit of `q` is a ten-log-point change in the effective-firm count. Gustavo is
treated as a Q4 stock observation, consistent with the existing variable
`N_Gustavo_annual_q4`:

```math
q_{y,Q4}^{*}=q_y^G.
```

Q1--Q3 are generated by allocating the Q4-to-Q4 annual change. No annual
measurement error is introduced.

The reporting center `q_0` is the time average of the measurement-only posterior
mean path over the common sample and is computed once before reading inflation
outcomes. For every posterior draw,

```math
q_t=q_t^{*}-q_0.
```

The center is fixed across draws and models. Draw-specific recentering is not
allowed.

## 4. Capital IQ quarterly-allocation module

For a year with four valid Capital IQ quarterly changes, define

```math
d^C_{yq}=10\Delta\log N^{CIQ}_{yq},
\qquad
w^{raw}_{yq}=\frac{d^C_{yq}}{\sum_{r=1}^4d^C_{yr}}.
```

An annual profile is called stable when

```math
\max_q|w^{raw}_{yq}|\le 3.
```

The average allocation profile is the componentwise median of the stable annual
profiles, renormalized to sum to one:

```math
\bar w_q=
\frac{\operatorname{median}_y(w^{raw}_{yq})}
{\sum_{r=1}^4\operatorname{median}_y(w^{raw}_{yr})}.
```

For every observed Capital IQ year, define the coherence weight

```math
c_y=
\frac{|\sum_q d^C_{yq}|}{\sum_q|d^C_{yq}|}\in[0,1].
```

The allocation prior mean is

```math
\mu_{w,y}=
\begin{cases}
c_yw_y^{raw}+(1-c_y)\bar w,&\text{four valid Capital IQ changes},\\
\bar w,&\text{otherwise}.
\end{cases}
```

Let `P = I_4 - 1_4 1_4'/4`. From the stable profiles form

```math
\Sigma_w=0.25\,P\widehat{\operatorname{Var}}(w_y^{raw})P.
```

The annual weight prior is Gaussian on the sum-to-one affine subspace:

```math
w_y\sim
\mathcal N_4\!\left(\mu_{w,y},(1-c_y)\Sigma_w\right),
\qquad 1_4'w_y=1.
```

For missing years set `c_y=0`. Negative quarterly weights are permitted because
the annual effective-firm count can temporarily reverse within a year. Every
draw must satisfy

```math
\sum_{q=1}^4w_{yq}=1.
```

Quarterly levels are

```math
q^*_{yq}=q^G_{y-1}+
\left(\sum_{r=1}^{q}w_{yr}\right)(q_y^G-q_{y-1}^G),
```

which implies the exact Q4 constraint. The first usable observation is 1974Q4;
no artificial 1974 Q1--Q3 observations enter the NKPC sample.

### Allocation cut

The allocation posterior is estimated only from Gustavo and Capital IQ.
Inflation is not allowed to update `w_y`. The main state/NKPC sampler integrates
over draws from this fixed measurement-only allocation posterior. This is the
only mandatory modular cut in the confirmatory analysis.

## 5. Exact slow/cycle state model

For every quarterly allocation draw,

```math
q_t=\bar q_t+\hat q_t
```

holds exactly. There is no competition measurement error. The state laws are

```math
\bar q_t=\bar q_{t-1}+\eta^b_t,
\qquad
\hat q_t=
2r\cos\!\left(\frac{2\pi}{P}\right)\hat q_{t-1}
-r^2\hat q_{t-2}+\eta^h_t,
```

with

```math
\eta^b_t\sim\mathcal N(0,\omega\tau^2),
\qquad
\eta^h_t\sim\mathcal N(0,(1-\omega)\tau^2).
```

The parameter meanings are fixed:

- `tau^2`: total quarterly innovation variance of the competition decomposition;
- `omega`: share allocated to the slow-state innovation;
- `r`: damping factor, equal to the modulus of the two complex cycle roots;
- `P`: cycle period in quarters.

Priors are

```math
\omega\sim\operatorname{Beta}(2,8),
```

```math
\tau^2\sim
\operatorname{IG}\!\left(3,2(0.15s_q)^2\right),
```

```math
u_r=\frac{r-0.25}{0.98-0.25}
\sim\operatorname{Beta}(8,2),
\qquad 0.25<r<0.98,
```

```math
P\sim\mathcal N(12,4^2)
\quad\text{truncated to }[6,20],
```

where `s_q` is the robust IQR scale of the fixed measurement-only posterior mean
path. Equivalently, the AR(2) coefficients are

```math
\phi_1=2r\cos(2\pi/P),
\qquad
\phi_2=-r^2.
```

This parameterization forces a stationary stochastic cycle and estimates its
frequency directly instead of letting an unrestricted AR(2) imitate a second
trend. The initial cycle pair uses the corresponding stationary covariance:

```math
\begin{pmatrix}\hat q_1\\ \hat q_2\end{pmatrix}
\mid r,P,\omega,\tau^2
\sim
\mathcal N\!\left(
0,
(1-\omega)\tau^2\Gamma(r,P)
\right),
```

where `Gamma(r,P)` is the stationary covariance under unit cycle-innovation
variance. At every date, including the two initial dates,
`bar q_t=q_t-hat q_t` exactly.

### State treatment

Every cell uses the exact-constraint joint split. Conditional on an allocation
draw, that cell's inflation likelihood and the state-transition laws jointly
update `bar q` and `hat q`. The equality `q=bar q+hat q` is preserved by
dimension reduction, not by a near-zero-variance observation equation.

No state-cut fit is estimated or reported in this revision.

## 6. Common NKPC block

For every model,

```math
\pi_t
=a+\alpha_b\pi_{t-1}
+\alpha_fE_t\pi_{t+1}
+\mathcal C_t
+\varepsilon_t,
```

where `C_t` is the model-specific activity and competition block. The inflation
disturbance is

```math
\varepsilon_t=\phi\varepsilon_{t-1}+u_t,
\qquad
u_t\sim\mathcal N(0,\sigma_\pi^2),
\qquad |\phi|<0.98.
```

No standalone empirical competition-level control `psi q_t` is included.
Competition timing is contemporaneous. A lag-one competition sensitivity is
reported only as a robustness exercise and is not mixed into the nested ladder.

Scale-derived coefficient priors use robust scales `s_pi`, `s_x`, and `s_q`:

```math
a\sim\mathcal N(0,(2s_\pi)^2),
```

```math
\alpha_b\sim\mathcal N(0.5,0.5^2),
\qquad
\alpha_f\sim\mathcal N(0.5,0.5^2),
```

```math
\kappa_0\sim\mathcal N\!\left(0,(0.5/s_x)^2\right),
```

```math
\delta_s
\sim\mathcal N\!\left(0,(0.2/(s_xs_q))^2\right),
```

```math
\theta\sim\mathcal N\!\left(0,(0.2/s_q)^2\right),
```

```math
\phi\sim\mathcal N(0,0.35^2)\text{ truncated to }(-0.98,0.98),
```

```math
\sigma_\pi^2\sim\operatorname{IG}\!\left(3,2(0.75s_\pi)^2\right).
```

The primary priors are sign-unrestricted. Positive-sign priors are not used to
establish a mechanism. The sharp restricted `theta` prior is the compatible
conditional prior in Section 9, rather than a newly chosen prior.

## 7. Primary empirical nested ladder

The primary negative-unemployment-gap block is reduced-form. Define:

### M0: CES baseline

```math
\mathcal C_t=\kappa_0x_t.
```

Restrictions: `delta_s=0`, `theta=0`.

### M1: slow slope channel

```math
\mathcal C_t=(\kappa_0+\delta_s\bar q_t)x_t.
```

Restriction: `theta=0`.

### M2: direct channel

```math
\mathcal C_t=\kappa_0x_t-\theta\hat q_t.
```

Restriction: `delta_s=0`.

### M3: free static combined — primary model

```math
\mathcal C_t
=(\kappa_0+\delta_s\bar q_t)x_t
-\theta\hat q_t.
```

The primary nesting relations are

```math
M0\subset M1\subset M3,
\qquad
M0\subset M2\subset M3.
```

`M1` and `M2` are not nested in one another.

The main report interprets `delta_s` and `theta` separately. It does not report
`lambda=delta_s/theta` when the posterior of `theta` includes a neighborhood of
zero.

## 8. Theory-near free and HSA-restricted ladder

This ladder is estimated only in the inverse-markup benchmark cell.

### B0--B3

`B0`--`B3` repeat `M0`--`M3` on the common inverse-markup sample.

### HSA(j): sharp HSA model for fixed lambda_j

```math
\mathcal C_t
=\kappa_0x_t
+\theta\left[\lambda_j\bar q_tx_t-\hat q_t\right].
```

It imposes

```math
\delta_s=\lambda_j\theta.
```

Therefore

```math
B0\subset HSA(j)\subset B3.
```

The empirical decomposition assigns the slow state to the slope channel and the
cycle to the direct channel. In the empirical `q` coordinate, the restriction is
therefore evaluated as

```math
\frac{d\kappa(\bar q)}{d\bar q}=\lambda\theta.
```

Here `lambda` is a multiplier in units of `q = 10 log F - q_0`. The structural
identity on a theoretical competition coordinate `N` is

```math
\frac{d\kappa(N)}{dN}=b_x\zeta\theta,
\qquad
\lambda^{(q)}=b_x\zeta\frac{dN}{dq}.
```

Consequently, `lambda = b_x zeta` is valid only if `q` and structural `N` use
the same normalization. Setting `b_x = 1` by itself is not sufficient. For
example, if structural `N = log F`, then `q = 10 N - q_0` and
`lambda^(q) = b_x zeta / 10`. The frozen values below are therefore empirical
`q`-coordinate sensitivity values; they must not be reported as demand
elasticities without an explicit coordinate mapping:

```text
zeta_grid = [3, 6, 9]
lambda_grid = [3, 6, 9]
primary legacy bridge value = 6
```

These values are calibration sensitivities, not estimates. If an external
reference-markup distribution is supplied, it is transformed by

```math
\zeta_{ref}=\frac{\mu_{ref}}{\mu_{ref}-1}
```

and propagated as a separate externally informed benchmark. It does not replace
the frozen grid in the reproducibility report.

### Free-lambda diagnostic

The diagnostic parameterization

```math
\delta_s=\lambda\theta,
\qquad \lambda\in\mathbb R
```

is not part of the nested evidence ladder. It spans essentially the same
two-dimensional coefficient space as free `(delta_s,theta)` away from `theta=0` and
is singular at `theta=0`. It is used only to display non-identification.

## 9. Compatible priors for formal nested Bayes factors

All confirmatory restricted fits use priors induced from the unrestricted `B3`
prior. Formal Savage--Dickey calculations are allowed only with these compatible
conditional priors.

In `B3`, let independent priors be

```math
\delta_s\sim\mathcal N(0,s_\delta^2),
\qquad
\theta\sim\mathcal N(0,s_\theta^2).
```

Under `HSA(j)`, conditioning on `delta_s-lambda_j theta=0` gives

```math
\theta\sim\mathcal N(0,s_{\theta,j}^{2}),
\qquad
s_{\theta,j}^{2}
=\left(
s_\theta^{-2}+\lambda_j^2/s_\delta^2
\right)^{-1}.
```

Each `HSA(j)` fit uses the displayed `theta` prior. Equivalently, the formal
Bayes factor may be computed from the `B3` posterior density at the restriction

```math
\delta_s-\lambda_j\theta=0.
```

If both routes are implemented, their log Bayes factors must agree within 0.10
on a simulated validation case. Any Bayes factor using a different restricted
prior is labeled a prior sensitivity rather than the formal nested Bayes factor.
Prior-versus-posterior plots are mandatory for every restricted coefficient.

## 10. Restriction diagnostics from the unrestricted posterior

For every calibration `lambda_j`, compute in unrestricted `B3`

```math
r_j=\delta_s-\lambda_j\theta.
```

Also compute the sample-path discrepancy in predicted inflation:

```math
D_{j,t}=r_j\bar q_tx_t.
```

Report:

1. posterior mean and 95% interval of `r_j`;
2. `P(r_j>0)`;
3. RMS discrepancy

   ```math
   A_j=\sqrt{T^{-1}\sum_tD_{j,t}^2};
   ```

4. the equivalence probability

   ```math
   P(A_j<0.10\text{ inflation percentage point}).
   ```

The 0.10-point band is frozen before estimation. A credible interval merely
containing zero is not called evidence for the equality.

## 11. Estimation sequence

The executable pipeline must implement these stages in order.

1. **Preflight**
   - verify input columns and dates;
   - verify positive Gustavo and Capital IQ counts;
   - verify that every Gustavo observation is calendar Q4;
   - freeze the common complete-case period index for each cell;
   - write input hashes and configuration to the manifest.
2. **Measurement-only allocation**
   - construct `bar w`, annual means, covariances, and allocation draws;
   - verify every annual weight sum and Q4 anchor;
   - freeze `q_0` and `s_q` without inflation outcomes.
3. **Quick state/NKPC run**
   - run all models with two chains and short sampling;
   - stop if identity, finite-likelihood, or rough-convergence gates fail.
4. **Full joint ladders by inflation outcome**
   - estimate `M0`--`M3` for PPI/negative-gap and Core-CPI/negative-gap;
   - estimate `B0`--`B3`, the three `HSA(j)` fits, and the free-lambda
     diagnostic separately for PPI/inverse-markup and Core-CPI/inverse-markup;
   - this is `4 + 8 + 4 + 8 = 24` independent joint-state fits.
5. **Predictive evaluation**
   - compute four-quarter-blocked PSIS-LOO for all converged full-sample fits;
   - refit any block with Pareto `k > 0.7` rather than accepting the importance
     approximation;
   - report WAIC as a secondary descriptive statistic, not as the primary
     time-series predictive criterion;
   - run annual-origin four-quarter forecast blocks with origins from `2003Q4`
     through `2012Q4` where data permit;
   - report summed log predictive density and RMSE on the identical forecast set.
6. **Marginal likelihood**
   - compute only with a state-integrating Chib or bridge-sampling implementation
     validated on a simulated nested case;
   - a cut-state Laplace approximation is not labeled a formal Bayes factor.
7. **Report generation**
   - generate tables, figures, machine-readable files, and the final PDF only
     after all gates and decision rules are evaluated.

## 12. Gates and decision rules

### 12.1 Numerical gates

Quick-run requirements:

- exact identity error `< 1e-10`;
- all saved values finite;
- maximum rank-normalized R-hat `<= 1.05`.

Full-run requirements:

- exact identity error `< 1e-10`;
- maximum rank-normalized R-hat `<= 1.01` for coefficients and state parameters;
- bulk ESS `>= 400` and tail ESS `>= 400` for every reported structural
  coefficient;
- no forecast or log-likelihood array contains non-finite values.

A model failing a full-run gate is excluded from substantive comparison and is
reported as `diagnostic failure`, not as evidence against its mechanism.

### 12.2 Competition-channel evidence

Relative to `M0`, a channel is classified using the four-quarter-blocked elpd:

- **supported**: `Delta elpd > 2 SE(Delta elpd)` and Bayes factor `> 3`, with the
  channel coefficient's directional probability at least `0.95`;
- **suggestive**: exactly one of the predictive or Bayes-factor conditions holds;
- **not supported**: neither condition holds;
- **conflicted**: predictive and marginal-likelihood rankings materially disagree.

If the validated marginal likelihood is unavailable, the status is explicitly
`predictive evidence only`; it is never filled with an approximate number.

`M3` must be at least suggestive relative to `M0` before any dynamic extension is
promoted beyond an appendix sensitivity.

### 12.3 Sharp HSA equality

For a given `lambda_j`, the equality is classified as **compatible** only if:

- `HSA(j)` is no more than one elpd standard error below `B3`;
- `BF[HSA(j):B3] >= 1/3`;
- `P(A_j < 0.10) >= 0.80`;
- `HSA(j)` is at least suggestive relative to `B0`.

It is classified as **supported** only if, in addition,
`BF[HSA(j):B3] > 3`. A positive restricted `theta` by itself is not evidence for
the equality.

### 12.4 Dynamic stopping rule

No confirmatory dynamic or quadratic model is run unless:

- `M3` is at least suggestive relative to `M0`; and
- at least one `lambda_j` is compatible in the inverse-markup benchmark.

If the rule passes, a new revision must pre-declare the dynamic encompassing
model and its exact HSA restrictions before estimation.

## 14. Naming rules

- Do not use `Joint` as a model name. `joint` describes a state-inference
  treatment, not a competition-channel specification.
- Use `free_static_combined` for `M3`.
- Use `hsa_fixed_lambda_<value>` for each sharp restricted model.
- Use `free_lambda_diagnostic` only for the non-identified diagnostic.
- Always identify the inflation and activity cell in manifests and report
  captions.

## 15. Reproducibility requirements

- All random seeds, iteration counts, prior constants, calibration grids, input
  hashes, sample dates, and software revision identifiers are written to the
  manifest.
- Quick and full results use separate directories.
- A full run never overwrites a prior full run with a different configuration;
  a changed configuration requires a revision suffix.
- Results are generated from saved posterior draws; report scripts do not rerun
  estimation.
- Existing unrelated workspace changes are not modified.
